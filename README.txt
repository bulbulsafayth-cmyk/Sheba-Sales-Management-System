SHEBA SALES - সফটওয়্যার হিসেবে ব্যবহারের নিয়ম
==============================================

এই ফোল্ডারটাই আপনার অ্যাপ (index.html + manifest + sw.js + icons)।
ইন্টারনেট লাগবে, কারণ ডাটা Supabase ক্লাউডে থাকে।

ধাপ ১: অ্যাপ অনলাইনে রাখুন (একবারই, ফ্রি)
- Netlify Drop (app.netlify.com/drop): পুরো sheba_app ফোল্ডারটা টেনে ছেড়ে দিন। একটা https লিংক পাবেন।
- অথবা Cloudflare Pages / GitHub Pages ব্যবহার করতে পারেন।
- লিংকটা https হতে হবে, নাহলে Install অপশন আসবে না।

ধাপ ২: ইনস্টল করুন
- কম্পিউটার (Chrome / Edge): লিংক খুলুন -> ঠিকানার ডানদিকে Install আইকন, অথবা অ্যাপের উপরের "⬇ Install app" বাটন।
- Android (Chrome): লিংক খুলুন -> মেনু (৩ ডট) -> Install app / Add to Home screen।
- iPhone (Safari): Share -> Add to Home Screen।
ইনস্টলের পর ডেস্কটপ/হোম স্ক্রিনে আইকন আসবে, আলাদা উইন্ডোতে খুলবে।

আপডেট করতে: নতুন ভার্সনের ফোল্ডার আবার একই জায়গায় আপলোড করুন। অ্যাপ পরের বার খুললে নতুন হয়ে যাবে।

সতর্কতা: লিংক পাবলিক হলে লগইন পেজ সবাই দেখতে পারবে। তাই Supabase-এর RLS পলিসি চালু রাখুন
(add_retailers.sql, allow_dso_edit.sql ইত্যাদি SQL চালানো থাকতে হবে)।
